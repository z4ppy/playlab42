Créer un bot

Un bot de jeu est un joueur automatique : une petite classe qui choisit une action légale. Ce n'est pas un agent IA de code, qui lui lit et modifie un dépôt.

Bot de jeu ou agent IA de code ?

Bot de jeuAgent IA de code
RôleJouer une partieAider à écrire, tester, documenter
EntréeVue du joueur et actions légalesInstructions, fichiers, outils
RésultatUne action, toujours la même pour la même entréeUn diff à relire
Oùgames/<id>/bots/Votre assistant, guidé par AGENTS.md

Le contrat

export class PrudentBot {
  name = 'Prudent';
  difficulty = 'easy';

  // view : vue publique du joueur ; validActions : coups légaux ;
  // rng : SeededRandom fourni si le bot a besoin de hasard.
  chooseAction(view, validActions, rng) {
    return validActions[0];
  }
}
export default PrudentBot;
  • Déterministe : pas de Math.random(), utilisez le rng fourni.
  • Aucun accès à l'état privé : seulement la vue et les actions légales.
  • Sans DOM ni réseau, comme le moteur.
  • Déclaré dans game.json, rubrique bots.available (name, file, difficulty).

Mini-exercice

Écrivez chooseAction pour un bot « Premier coup » qui joue toujours la première action légale, puis dites s'il est déterministe.

Correction 
chooseAction(_view, validActions) {
  return validActions[0];
}

Oui : même entrée, même sortie. Pour un bot aléatoire, il faudrait passer par rng.pick(validActions) avec une seed fixe.
