Créer un outil

Un outil est une petite application web sans backend. Il vit dans son dossier tools/<id>/ et se déclare avec un manifest : sans tool.json, le catalogue l'ignore.

Ce qu'il faut

tools/mon-outil/
├── index.html   # point d'entrée (obligatoire)
├── tool.json    # manifest (obligatoire)
└── main.js      # modules locaux, optionnel
  • tool.json exige id (kebab-case), name, description et tags (tableau) ; version est optionnelle, au format 1.0.0.
  • Les modules locaux sont permis ; servez le projet en HTTP, pas via file://.
  • Réutilisez lib/theme.css, lib/ui.css et lib/components.css (classes ui-*).
  • Pas de backend : tout tourne dans le navigateur, les données restent locales.

Générer, essayer, cataloguer

  1. Générez le squelette avec Docker (jamais Node sur l'hôte) : 
    make scaffold TYPE=tool ID=mon-compteur TITLE="Mon compteur"
    Cette cible exécute npm run scaffold -- tool mon-compteur --title "Mon compteur" dans le conteneur. Un dossier existant n'est jamais écrasé : il n'y a pas d'option --force.
  2. Lancez le serveur : make serve, puis ouvrez l'URL donnée par make info.
  3. Régénérez le catalogue : 
    make npm CMD="run build:catalogue"
  4. Dans le portail, onglet Outils, cherchez « compteur » et ouvrez la carte.

La galerie UI

La galerie UI Playlab42 montre les composants partagés avec leur thème : boutons, champs, cartes, statuts et dialogue natif. Copiez ses classes plutôt que d'écrire un CSS maison ; gardez les éléments natifs et leurs libellés.

Mini-exercice

Votre outil mon-compteur n'apparaît pas dans l'onglet Outils. Citez deux causes probables.

Correction
  • Le catalogue n'a pas été régénéré : lancez make npm CMD="run build:catalogue".
  • Le manifest est invalide (champ requis manquant, id non kebab-case) ou index.html est absent : le build signale l'erreur.
