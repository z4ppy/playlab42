Policy-as-Code : la gouvernance automatisée

Le Policy-as-Code transforme des règles d'organisation en code relu, testé et appliqué automatiquement. Open Policy Agent évalue des politiques écrites en Rego. Depuis OPA 1.0, publié le 20 décembre 2024, les mots-clés if et contains sont obligatoires [25].

Cet exemple valide un manifeste brut, par exemple en CI avec opa eval : chaque message produit par deny signale une ressource refusée. Pour l'appliquer à l'admission dans un cluster, OPA s'intègre à Kubernetes via Gatekeeper, mais la règle doit alors être adaptée : Gatekeeper attend une règle violation qui lit l'objet dans input.review.object, déclarée dans un ConstraintTemplate [26]. D'autres approches existent : Kyverno décrit ses politiques en YAML, et les ValidatingAdmissionPolicy intégrées à Kubernetes, stables depuis la version 1.30, utilisent le langage CEL [27].
