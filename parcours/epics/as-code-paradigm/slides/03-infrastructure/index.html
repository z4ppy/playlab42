Infrastructure as Code

Outils et pratiques

Serveurs, réseaux et bases de données décrits dans des fichiers : la forme la plus répandue du paradigme.

L'essor des outils déclaratifs

Le 25 février 2011, AWS lance CloudFormation, qui crée une pile complète de ressources à partir d'un modèle décrit dans un fichier [11]. Le 28 juillet 2014, Mitchell Hashimoto annonce Terraform, pensé dès l'origine pour plusieurs fournisseurs grâce à des providers extensibles [12]. Autour de lui, quelques outils structurent la décennie.

  • 🏗️Terraform

    Depuis 2014 [12]

    Infrastructure multi-cloud décrite en HCL et étendue par des providers.

  • ⚙️Ansible

    Depuis 2012 [13]

    Configuration sans agent, par SSH, avec des playbooks YAML.

  • 📦Docker

    Depuis 2013 [14]

    Conteneurs construits depuis un Dockerfile : des images immuables.

  • ☸️Kubernetes

    Depuis 2014 [15]

    Orchestration déclarative de conteneurs par manifestes YAML.

Cattle vs Pets

Une métaphore résume ce changement : Cattle vs Pets, le bétail contre les animaux de compagnie. Bill Baker l'emploie d'abord pour opposer deux façons de faire grandir SQL Server ; Randy Bias l'adopte en 2011 ou 2012 pour expliquer le cloud [16]. Un serveur « animal de compagnie » est unique, soigné à la main et irremplaçable. Un serveur « bétail » est interchangeable : on le détruit et on le recrée depuis sa description. Ce n'est plus le serveur qui compte, mais le code qui le décrit.

Quatre générations d'outils

Découpage indicatif : les générations se chevauchent.
Génération Période Outils Apport
1re 1993-2004 CFEngine Configuration automatisée, convergence
2e 2005-2010 Puppet, Chef Langages déclaratifs dédiés
3e 2011-2016 CloudFormation, Terraform, Ansible, Docker Cloud, multi-fournisseurs, conteneurs
4e Depuis 2017 Argo CD, Flux, Crossplane GitOps, plans de contrôle Kubernetes

2023-2025 : licence, fork et rachat. Le 10 août 2023, HashiCorp annonce que ses futures versions, dont celles de Terraform, passent de la licence MPL 2.0 à la Business Source License 1.1 [17]. Le 20 septembre 2023, la Linux Foundation lance OpenTofu, un fork resté open source [18], que la CNCF accepte en sandbox le 23 avril 2025 [19]. Entre-temps, IBM a finalisé le rachat de HashiCorp le 27 février 2025 [20].
