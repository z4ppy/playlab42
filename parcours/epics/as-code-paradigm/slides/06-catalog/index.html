Outils et pratiques

Services, outils, contenus : des inventaires tenus avec la même rigueur que le code applicatif.

Gérer un inventaire comme du code

Le Catalog-as-Code applique le paradigme aux inventaires : catalogues de logiciels, collections de contenus, registres de composants, listes de ressources. Fini les feuilles de calcul orphelines et les wikis délaissés. Les données vivent dans des fichiers versionnés, ajouter une entrée revient à ouvrir une pull request, et un pipeline vérifie la cohérence avant de générer un site, souvent statique.

Backstage, le catalogue des développeurs

Annoncé en open source par Spotify le 16 mars 2020 [29], Backstage est un projet CNCF en incubation depuis le 15 mars 2022 [31]. Son catalogue lit des fichiers catalog-info.yaml, inspirés des manifestes Kubernetes, placés à côté du code de chaque composant. Pour un Component, les champs spec.type, spec.lifecycle et spec.owner sont obligatoires [30].

Playlab42, un catalogue as-code

Le portail que vous lisez applique ce principe [32]. Chaque jeu décrit ses métadonnées dans game.json, chaque parcours dans epic.json et chaque étape dans slide.json. Des scripts de build les valident puis génèrent les fichiers data/*.json, jamais modifiés à la main et absents du dépôt. Publier ce parcours, c'est fusionner une pull request.
