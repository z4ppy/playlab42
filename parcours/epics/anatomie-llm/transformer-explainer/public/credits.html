Poids, tokenizer et moteur

GPT-2 small : 124 millions de paramètres, 12 blocs, 12 têtes, états cachés de dimension 768, vocabulaire de 50 257 tokens. L’export instrumenté ONNX de Polo Club est constitué de 63 fichiers, au total 656 662 664 octets (656,7 Mo / 626,2 Mio). Ce sont les poids réels exportés par l’amont, pas un autre modèle fourni par une API. L’exporteur amont utilise GPT2LMHeadModel.from_pretrained('gpt2') pour reprendre les poids de GPT-2. Après consentement, le navigateur charge une copie statique sur ce site lorsqu’elle a été préparée ; sinon, il utilise raw.githubusercontent.com, à la révision ci-dessus. La source choisie est annoncée avant le clic. Aucun serveur de génération ni relais de modèle n’est requis. Les sommes SHA-256 sont consignées dans le manifeste.

Les poids GPT-2 sont distribués sous MIT selon la fiche du modèle d’origine. La licence MIT modifiée d’OpenAI est conservée : les textes créés vous appartiennent, mais ils doivent être utilisés de façon responsable et identifiés comme générés par GPT-2. GPT-2 est surtout anglophone ; il peut produire des textes biaisés, faux ou inappropriés.

Le tokenizer local provient de Xenova/gpt2, révision bf2c7f02e0b826c60d03af341171bde20893da66. Il reprend le vocabulaire GPT-2. ONNX Runtime Web 1.23.0 (Microsoft, MIT) et Transformers.js 2.17.2 (Hugging Face, Apache-2.0) sont intégrés localement. Les licences des dépendances sont livrées dans les notices tierces.

Confidentialité, réseau et limites

Aucun prompt ni événement d’usage n’est envoyé. Les téléchargements des poids ne contiennent pas le prompt. Comme pour toute requête HTTP, l’hébergeur distant peut voir votre adresse IP et les métadonnées de connexion. Il n’y a ni script CDN automatique, ni télémétrie, ni compte nécessaire. Le navigateur peut conserver les poids en cache, mais aucun mode hors ligne n’est garanti. Le chargement nécessite une connexion et plusieurs Go de mémoire disponibles. HTTPS ou localhost est nécessaire pour vérifier les SHA-256. Un blocage réseau/CORS est une erreur, pas une réussite native. Le bouton Réessayer réutilise les morceaux vérifiés si le cache est autorisé.

Les noms mathématiques standard (Q, K, V, logits, softmax, MLP, GELU) restent utilisés. Certains détails des fenêtres avancées de poids conservent des formulations anglaises de l’amont. La génération se fait un token à la fois, pour des prompts courts (25 mots, 48 tokens au maximum).
