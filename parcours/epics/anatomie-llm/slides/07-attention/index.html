1 · AVANT DE MANIPULER

Comprendre le mécanisme.

Retrouvons le calcul pas à pas sous forme de grille. Une ligne est le token qui consulte ; une colonne, le token consulté. Une case donne le poids utilisé pour mélanger son V. Les projections Q et K fixent les scores, le masque interdit le futur, softmax donne les poids, puis la tête combine les V.

Le masque causal interdit de regarder les positions futures. À l’entraînement, on peut calculer plusieurs prédictions en parallèle tout en respectant cette contrainte. À l’inférence autorégressive, les nouvelles positions arrivent successivement.

Pourquoi la diagonale est-elle autorisée ? La représentation de « chat » utilise déjà « chat » pour prédire le token suivant. Consulter sa propre position est donc permis. Chaque ligne a sa propre distribution totalisant 100 % ; les colonnes n’ont pas cette contrainte.

La grille montre les véritables poids d’attention de Luciole. Changez de tête pour voir un autre mélange du même texte, puis de bloc pour voir une autre étape. Deux blocs sont successifs ; quatre têtes sont parallèles dans chacun. Une case intense n’est pas une explication exhaustive de la décision finale.

Facultatif · notation mathématique

Attention(Q,K,V) = softmax(QKᵀ / √dₖ + masque) V. Le produit scalaire dépend des directions et des longueurs, pas seulement de l’angle. dₖ = 8 coordonnées par tête dans Luciole. Les scores futurs sont exclus avant softmax ; leurs poids sont nuls.

ligne = token qui consulte · colonne = token consulté · × = futur interdit

À RETENIR

L’attention est une opération de mélange pondéré, contrainte par le masque causal.

LES LIMITES

« Causal » signifie ici que le futur est masqué. Une grande valeur d’attention ne prouve pas, à elle seule, qu’un token a causé la réponse finale.

Le vocabulaire de cette étape
tête
Un des calculs d’attention effectués en parallèle dans un bloc. Dans Luciole, chaque tête possède ses matrices de projection pour Q, K et V.
attention
Opération qui mélange les informations des tokens en leur donnant des poids différents.
q/k/v
Query, Key, Value : requête, clé, valeur. Q et K déterminent les proportions du mélange ; V fournit les nombres à mélanger.
masque causal
Contrainte interdisant à une position de consulter les positions futures.
softmax
Transforme des scores quelconques en nombres positifs dont la somme vaut 1 : une distribution de probabilités.
poids d’attention
Coefficients calculés par softmax après les scores Q·K et le masque, pour mélanger les valeurs V. Une ligne totalise 1.

3 · VÉRIFIER SA COMPRÉHENSION

Pourquoi les cases au-dessus de la diagonale sont-elles masquées ?

Lire la correction

Pour empêcher la fuite d’information depuis le futur. La cible ne doit pas être visible dans l’entrée utilisée pour la prédire.
