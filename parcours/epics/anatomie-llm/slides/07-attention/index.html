1 · AVANT DE MANIPULER

Comprendre le mécanisme.

Lire la grille

Chaque ligne est un token qui consulte ; chaque colonne, un token consulté. La case à l’intersection donne la part du V de la colonne dans le mélange de la ligne : ce sont les poids d’attention. Chaque ligne totalise 100 %, puisque c’est un partage ; les colonnes n’ont pas cette contrainte.

Pourquoi un triangle ?

Les cases au-dessus de la diagonale sont vides : c’est le masque causal. Un token ne voit que lui-même et ce qui le précède. La raison vient de l’entraînement : le modèle apprend à prédire le token suivant, il ne doit donc pas pouvoir le lire. Grâce à ce masque, une seule phrase fournit autant d’exercices que de positions, tous calculés en parallèle.

Et la diagonale ? Elle est autorisée. La position « chat » sert à prédire ce qui vient après « chat » ; se consulter elle-même ne révèle donc rien du futur.

Ce que montre l’expérience

La grille affiche les vrais poids d’attention de Luciole. Changez de tête : même texte, autre mélange, car chaque tête a ses propres projections. Changez de bloc : le bloc 2 travaille sur des vecteurs déjà enrichis par le bloc 1. Si une tête place une grande part de son attention sur <bos>, ce n’est pas un défaut : dans les grands modèles aussi, le premier token sert souvent de « point de repos » quand aucun autre n’apporte d’information utile.

Pour les avertis · la formule complète

Attention(Q, K, V) = softmax(QKᵀ / √dk + M) V, où M vaut −∞ au-dessus de la diagonale et 0 ailleurs ; dk = 8 dans Luciole. Le produit scalaire dépend des directions et des longueurs des vecteurs. Un poids élevé indique où l’information a été lue, pas qu’elle a causé la prédiction finale : la valeur V lue peut être petite, et la suite du réseau peut l’ignorer.

ligne = token qui consulte · colonne = token consulté · case vide = futur interdit

À RETENIR

L’attention est un mélange pondéré : chaque ligne répartit 100 % entre le token lui-même et ses prédécesseurs, jamais ses successeurs.

LES LIMITES

« Causal » désigne ici le masque du futur, pas une relation de cause à effet. Une case intense ne prouve pas, à elle seule, qu’un token a causé la réponse finale.

Le vocabulaire de cette étape
tête
Un des calculs d’attention effectués en parallèle dans un bloc. Dans Luciole, chaque tête possède ses matrices de projection pour Q, K et V.
attention
Opération qui mélange les informations des tokens en leur donnant des poids différents.
q/k/v
Query, Key, Value : requête, clé, valeur. Q et K déterminent les proportions du mélange ; V fournit les nombres à mélanger.
masque causal
Contrainte interdisant à une position de consulter les positions futures.
softmax
Transforme des scores quelconques en nombres positifs dont la somme vaut 1 : une distribution de probabilités.
poids d’attention
Coefficients calculés par softmax après les scores Q·K et le masque, pour mélanger les valeurs V. Une ligne totalise 1.

3 · VÉRIFIER SA COMPRÉHENSION

Pourquoi les cases au-dessus de la diagonale sont-elles masquées ?

Lire la correction

Pour empêcher de lire le token que l’on doit prédire. À l’entraînement, la cible de chaque position est le token suivant : elle ne doit pas être visible dans l’entrée qui sert à la prédire.

Notes pour une présentation animée

Accroche : le futur est fermé. Manipulation : première ligne, dernière ligne, autre tête. Transition : le masque connaît l’ordre, mais comment le modèle sait-il où se trouve chaque token ?
