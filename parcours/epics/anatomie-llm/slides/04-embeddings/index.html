1 · AVANT DE MANIPULER

Comprendre le mécanisme.

La table d’embeddings associe à chaque token un vecteur de dimension fixe. C’est d’abord une lecture de ligne dans une matrice apprise. Luciole utilise 32 dimensions ; un modèle de production en utilise souvent des milliers.

Trois moments à distinguer : le même ID lit toujours la même ligne d’embedding. Luciole y ajoute ensuite le vecteur de sa position. Les blocs produisent enfin des représentations contextualisées, dépendantes des tokens accessibles. « chat » part donc du même embedding dans deux phrases, mais son état peut évoluer différemment. Notre petit corpus ne suffit pas à démontrer une compréhension générale des ambiguïtés.

La similarité cosinus compare des directions à partir des 32 coordonnées. L’atlas 3D permet d’en choisir trois et de faire tourner la vue. Les vingt-neuf autres sont cachées : deux points proches à l’écran ne prouvent ni synonymie ni proximité dans l’espace complet. Les coordonnées viennent des vrais poids de Luciole, pas d’une carte inventée.

Facultatif · notation de la table

E ∈ ℝᵛˣᵈ : v tokens dans le vocabulaire, d nombres par token. L’embedding du token d’identifiant i est la ligne i de E, pas une multiplication du numéro i par un sens.

Dans le code de Luciole · Lire les embeddings et ajouter les positions

gather lit les lignes de la table demandées par les IDs. Le second gather lit les positions 0, 1, 2… add additionne les deux tableaux. Aucune recherche de sens dans un dictionnaire n’est effectuée.

  const embedding = gather(weights.token, ids);
  let x = add(embedding, gather(weights.position, ids.map((_, i) => i)));

À RETENIR

Un embedding est une représentation apprise, pas un dictionnaire de concepts lisibles dimension par dimension.

LES LIMITES

Nos voisins sont ceux d’un minuscule corpus. N’en déduisez pas une géographie universelle du langage.

Le vocabulaire de cette étape
embeddings
Vecteurs appris associés aux identifiants des tokens.
vecteur
Liste ordonnée de nombres. Ici, chaque token est représenté par 32 coordonnées.
dimension
Une des coordonnées d’un vecteur. Un vecteur de dimension 32 contient 32 nombres.
similarité cosinus
Mesure de l’alignement de deux vecteurs : 1 pour la même direction, 0 pour des directions perpendiculaires, −1 pour des directions opposées.

3 · VÉRIFIER SA COMPRÉHENSION

Une dimension d’embedding signifie-t-elle nécessairement « masculin », « ville » ou « positif » ?

Lire la correction

Non, les représentations sont généralement distribuées. L’information peut être distribuée entre de nombreuses directions. Une interprétation exige des observations et des expériences supplémentaires.
