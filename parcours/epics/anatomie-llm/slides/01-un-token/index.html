1 · AVANT DE MANIPULER

Comprendre le mécanisme.

Le prompt est le texte de départ. Le contexte est tout le texte disponible pour continuer : le prompt, puis les tokens déjà ajoutés. Un modèle de langage calcule une probabilité pour chaque token possible du vocabulaire. La stratégie de décodage en choisit un, l’ajoute au contexte, puis recommence jusqu’à un signal de fin ou une limite.

Exemple : après « le chat », un token possible est « dort ». Une fois choisi, le contexte devient « le chat dort » ; le calcul suivant propose la suite de ce nouveau texte. Le modèle ne produit donc pas une phrase complète en une seule décision.

Notre instrument : Luciole. C’est un mini-Transformer entraîné pour ce cours sur un petit ensemble de phrases, appelé corpus. Ses calculs sont réels, ses capacités limitées. Les poids sont les nombres ajustés pendant son entraînement : ils restent fixes lorsque vous générez du texte. La prochaine étape présente ce modèle et ses limites mesurées.

Deux gestes que nous allons découvrir : l’attention fait circuler l’information entre les tokens ; le MLP (Multi-Layer Perceptron, un petit réseau de neurones) transforme ensuite les nombres de chaque position. Il reçoit ainsi une information déjà enrichie par le contexte. Pour commencer, retenez simplement : mélanger, puis transformer.

Pour prendre vos repères : un vecteur est une liste de nombres ; une matrice, un tableau de nombres ; une probabilité, une valeur entre 0 et 1. Des étapes intermédiaires introduisent ces notions avant de les combiner. Le parcours Deep Learning pour l’impatient offre aussi une première exploration. Comptez environ 110 minutes ici, à votre rythme.

contexte → probabilités → choix → nouveau contexte ↻

À RETENIR

À chaque tour, le modèle calcule des scores à partir du contexte ; le décodage choisit le token à ajouter.

LES LIMITES

Un texte plausible n’est pas nécessairement vrai. La probabilité linguistique n’est pas une mesure de vérité.

Le vocabulaire de cette étape
token
Petite unité utilisée pour découper le texte : mot, morceau de mot, signe ou octet selon le tokenizer. Le modèle manipule le numéro associé à cette unité.
prompt
Entrée fournie au modèle avant qu’il produise une suite. Dans un chat, elle peut inclure tout l’historique et les consignes.
contexte
Suite de tokens disponible pour calculer la prochaine prédiction : le prompt et les tokens déjà générés.
poids
Nombres ajustés pendant l’entraînement et conservés pendant la génération. Ils déterminent les transformations du modèle.
mlp
Petit réseau de neurones qui transforme les nombres de chaque token, sans consulter directement les autres positions.
eos
End Of Sequence : marqueur de fin de séquence. La boucle de génération s’arrête lorsqu’il est choisi.

3 · VÉRIFIER SA COMPRÉHENSION

Que reçoit le modèle après avoir généré un token ?

Lire la correction

Le contexte enrichi du token choisi. Le contexte grandit. Un cache peut éviter de recalculer certaines représentations, mais les poids ne changent pas pendant cette inférence.
