1 · AVANT DE MANIPULER

Comprendre le mécanisme.

L’idée en une phrase

Un LLM (Large Language Model, grand modèle de langage) répond sans cesse à la même question : « quel morceau de texte vient ensuite ? » Ce morceau s’appelle un token : souvent un mot, parfois un morceau de mot ou un signe de ponctuation. L’image la plus proche est la suggestion de mot du clavier d’un téléphone, avec un modèle beaucoup plus riche qui tient compte de tout le texte précédent.

La boucle de génération

On part d’un prompt, le texte de départ. Le modèle attribue un score à chaque token qu’il connaît, puis une règle de décodage en choisit un. Ce token est ajouté au texte, qui forme le nouveau contexte, et tout recommence. La boucle s’arrête quand le modèle choisit un marqueur de fin, noté <eos>, ou quand une limite de longueur est atteinte.

Exemple : après « le chat », le modèle peut proposer « dort ». Le contexte devient « le chat dort » et le calcul suivant porte sur ce nouveau texte. Une réponse de cent tokens, ce sont donc cent décisions successives, chacune prise sans connaître les suivantes.

Ce qui change, ce qui ne change pas

Les poids sont les nombres réglés pendant l’entraînement : des milliards dans un grand modèle. Ils contiennent tout ce que le modèle a appris et restent fixes pendant qu’il vous répond. Seul le contexte grandit. Un modèle ne retient donc pas une conversation en modifiant ses poids : elle fait partie de son entrée à chaque tour.

Notre instrument : Luciole

Pour ouvrir la machine, nous utilisons Luciole, un mini-modèle entraîné pour ce cours. Ses calculs sont réels et s’exécutent dans votre navigateur ; ses capacités sont celles d’un modèle minuscule. L’étape suivante le présente.

La carte du voyage

  1. Du texte aux nombres : découper le texte en tokens, puis remplacer chaque token par une liste de nombres.
  2. À l’intérieur du Transformer : répéter deux gestes. L’attention fait circuler l’information entre les tokens ; le MLP (Multi-Layer Perceptron, un petit réseau de neurones) transforme ensuite les nombres de chaque token. Mélanger, puis transformer.
  3. Du calcul à la réponse : convertir des scores en probabilités, choisir, puis comprendre ce qu’un assistant ajoute autour.
  4. Mémoire, coûts et apprentissage : ce qu’il faut stocker, ce qui ralentit, d’où viennent les poids.
  5. Tout assembler : un laboratoire complet, une sonde à l’intérieur, puis un modèle public 3 200 fois plus grand.

Aucun prérequis mathématique. Vecteurs et matrices sont introduits pas à pas à l’étape 5. Pour découvrir d’abord les réseaux de neurones, voir Deep Learning pour l’impatient. Comptez environ 110 minutes, à votre rythme.

À RETENIR

Un LLM produit une réponse token par token : à chaque tour, il calcule des scores à partir du contexte, un token est choisi puis ajouté au contexte.

LES LIMITES

Un texte plausible n’est pas forcément vrai : le modèle prédit ce qui est probable dans la continuité de ses données, pas ce qui est exact.

Le vocabulaire de cette étape
token
Petite unité utilisée pour découper le texte : mot, morceau de mot, signe ou octet selon le tokenizer. Le modèle manipule le numéro associé à cette unité.
prompt
Entrée fournie au modèle avant qu’il produise une suite. Dans un chat, elle peut inclure tout l’historique et les consignes.
contexte
Suite de tokens disponible pour calculer la prochaine prédiction : le prompt et les tokens déjà générés.
poids
Nombres ajustés pendant l’entraînement et conservés pendant la génération. Ils déterminent les transformations du modèle.
mlp
Petit réseau de neurones qui transforme les nombres de chaque token, sans consulter directement les autres positions.
eos
End Of Sequence : marqueur de fin de séquence. La boucle de génération s’arrête lorsqu’il est choisi.
