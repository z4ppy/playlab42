1 · AVANT DE MANIPULER

Comprendre le mécanisme.

Une liste de nombres : le vecteur

Un vecteur est une liste ordonnée de nombres, par exemple [0,4 ; −0,2 ; 0,8]. Chaque case est une coordonnée ; le nombre de cases est sa dimension, ici 3. Dans un LLM, chaque token est représenté par un vecteur : 32 nombres dans Luciole, plusieurs milliers dans un grand modèle.

Une analogie utile : une fiche de description. Les cases d’une fiche « couleur, taille, poids » décrivent un objet ; les cases d’un vecteur de token décrivent ce token. La différence est que personne n’a nommé les cases : leur rôle émerge de l’entraînement et n’a, en général, pas de sens humain simple.

Un tableau de listes : la matrice

Une matrice range plusieurs vecteurs en lignes. Pour une phrase de 3 tokens décrits par 3 nombres chacun, on obtient un tableau 3 × 3. Dans Luciole, pour n tokens, la forme est n × 32 : une ligne par token, une colonne par coordonnée. La forme indique la taille des données, pas leur signification.

Transformer une liste : la somme pondérée

L’opération de base d’un réseau de neurones consiste à fabriquer un nouveau nombre en multipliant chaque coordonnée par un coefficient, puis en additionnant. Avec les coordonnées [2 ; 3] et les coefficients [0,4 ; −0,2] : 2 × 0,4 + 3 × (−0,2) = 0,2. Répéter ce calcul avec d’autres coefficients donne les autres coordonnées de sortie. Ranger tous ces coefficients dans une matrice, c’est faire une multiplication par une matrice, aussi appelée projection. Les coefficients sont les fameux poids appris.

Le tableau de l’expérience est inventé pour apprendre à lire la notation. Les vrais vecteurs de Luciole arrivent à l’étape suivante.

vecteur = une liste · matrice n × d = n listes de d nombres · projection = sommes pondérées

À RETENIR

Une ligne de la matrice décrit un token ; sa forme n × d donne le nombre de tokens et de coordonnées. Une projection fabrique de nouvelles coordonnées par sommes pondérées.

LES LIMITES

Les trois nombres par token de cette étape sont inventés pour apprendre la notation. Une valeur négative n’est pas « mauvaise » et une grande valeur n’est pas forcément importante.

Le vocabulaire de cette étape
vecteur
Liste ordonnée de nombres. Ici, chaque token est représenté par 32 coordonnées.
dimension
Une des coordonnées d’un vecteur. Un vecteur de dimension 32 contient 32 nombres.
matrice
Tableau de nombres organisé en lignes et colonnes. « n × 32 » signifie n lignes de 32 nombres.
