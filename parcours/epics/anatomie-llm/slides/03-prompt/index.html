1 · AVANT DE MANIPULER

Comprendre le mécanisme.

Le chat template est le gabarit qui assemble la conversation : instructions du système, messages de l’utilisateur et réponses de l’assistant. Il ajoute des marqueurs de rôle, des séparateurs et parfois un début de réponse. Cette conversion en une suite ordonnée de tokens s’appelle la sérialisation. Les formats varient selon les modèles.

Un agent ajoute souvent des descriptions d’outils, leurs arguments et leurs résultats. Ces contenus peuvent consommer une part importante du contexte. Ils ne deviennent pas pour autant des instructions fiables : le résultat d’un outil peut contenir du texte hostile.

Qui exécute un outil ? Le modèle peut produire une demande structurée. Le programme qui l’entoure décide de l’exécuter, récupère le résultat, puis le replace dans le contexte pour un nouveau calcul. Générer les caractères d’un appel n’exécute pas cet appel à lui seul.

L’échange ci-dessous est inventé pour le cours. Ses marqueurs sont illustratifs. Aucun raisonnement interne caché n’est montré ; un raisonnement affiché ne serait pas non plus une radiographie exhaustive du calcul.

messages + rôles + outils + template = entrée sérialisée

À RETENIR

Le prompt est une structure sérialisée, pas seulement la dernière question de l’utilisateur.

LES LIMITES

L’ordre et les marqueurs dépendent du modèle. Luciole n’utilise pas ce template : il reçoit des tokens lexicaux et n’a pas appris à converser ni à appeler des outils.

Le vocabulaire de cette étape
prompt
Entrée fournie au modèle avant qu’il produise une suite. Dans un chat, elle peut inclure tout l’historique et les consignes.
contexte
Suite de tokens disponible pour calculer la prochaine prédiction : le prompt et les tokens déjà générés.
chat template
Recette qui transforme les messages et leurs rôles en la séquence attendue par un modèle conversationnel.
token
Petite unité utilisée pour découper le texte : mot, morceau de mot, signe ou octet selon le tokenizer. Le modèle manipule le numéro associé à cette unité.

3 · VÉRIFIER SA COMPRÉHENSION

Le résultat d’un outil est-il automatiquement une instruction de confiance ?

Lire la correction

Non, il peut contenir des données non fiables. L’origine outil ne garantit pas la confiance du contenu. Données, instructions et autorisations doivent rester distinctes.
