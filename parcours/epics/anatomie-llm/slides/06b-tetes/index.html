1 · AVANT DE MANIPULER

Comprendre le mécanisme.

À quoi servent ces trois lettres ?

Dans « le chat dort », regardons la position « chat ». Nous voulons enrichir sa représentation avec les informations des positions qu’elle peut consulter : « le » et elle-même. Q et K calculent dans quelles proportions mélanger ; V fournit les nombres à mélanger.

Chaque token produit les trois listes Q, K et V. Ce ne sont pas trois sortes de mots. On obtient ces listes en multipliant sa représentation par trois matrices différentes, apprises pendant l’entraînement. Séparer les projections permet de choisir comment comparer sans imposer de transporter exactement les mêmes coordonnées comme contenu.

Suivre une seule position

Le Q de « chat » est comparé au K de chaque position : on multiplie les coordonnées correspondantes, puis on additionne. C’est le produit scalaire. On divise ensuite par la racine du nombre de coordonnées de la tête, pour contrôler l’échelle des scores. Le masque causal interdit « dort », situé après « chat ». Softmax transforme les scores autorisés en proportions positives totalisant 100 %. Ces proportions servent à additionner les V pondérés.

Et les autres têtes ?

Dans Luciole, chaque bloc possède quatre têtes de 8 coordonnées. Chacune calcule son mélange avec ses projections ; leurs sorties sont mises bout à bout, puis projetées vers 32 coordonnées. L’ajout résiduel conserve aussi l’entrée. Les têtes ne sont pas des spécialistes humains avec un rôle garanti.

Les schémas ci-dessous utilisent les nombres inventés du premier mode de l’expérience. Le mode « Vraie trace Luciole » montre ensuite les tenseurs du modèle, avec <bos>. Les matrices de poids restent fixes dans les deux cas.

Dans le code de Luciole · Les trois projections dans forward()

matmul multiplie deux matrices. i désigne le bloc ; weights contient ses paramètres appris. Les trois projections produisent ici 32 coordonnées, ensuite réparties entre quatre têtes de 8 coordonnées par attention().

    const normalized = rmsnorm(x);
    const q = matmul(normalized, weights[`${i}.q`]);
    const k = matmul(normalized, weights[`${i}.k`]);
    const v = matmul(normalized, weights[`${i}.v`]);
    const attended = attention(q, k, v, config.heads);

À RETENIR

Une tête est une façon apprise de mélanger des informations. Plusieurs têtes réalisent plusieurs mélanges en parallèle.

LES LIMITES

Le petit calcul est inventé ; le mode Luciole lit ses vrais tenseurs sans changer les poids. L’attention mélange des informations, le MLP transforme séparément chaque position ; aucune tête n’a de rôle humain garanti.

Le vocabulaire de cette étape
tête
Un des calculs d’attention effectués en parallèle dans un bloc. Dans Luciole, chaque tête possède ses matrices de projection pour Q, K et V.
q/k/v
Query, Key, Value : requête, clé, valeur. Q et K déterminent les proportions du mélange ; V fournit les nombres à mélanger.
projection
Conversion d’un vecteur par multiplication avec une matrice de paramètres appris.
produit scalaire
Somme des produits des coordonnées correspondantes de deux vecteurs. Sert notamment à calculer les scores d’attention.
masque causal
Contrainte interdisant à une position de consulter les positions futures.
softmax
Transforme des scores quelconques en nombres positifs dont la somme vaut 1 : une distribution de probabilités.
concaténation
Mise bout à bout de listes de nombres. Les sorties des quatre têtes de Luciole sont réunies avant une nouvelle projection.
résidu
Chemin qui ajoute l’entrée d’un sous-bloc à sa sortie, à dimensions compatibles.

3 · VÉRIFIER SA COMPRÉHENSION

À la position « chat » dans « le chat dort », quels V peuvent contribuer au mélange causal ?

Lire la correction

V de « le » et de « chat », mais pas du futur « dort ». Le masque interdit le futur avant softmax. Dans la vraie trace Luciole, V de <bos> est aussi autorisé. Le mélange transforme la représentation ; il ne tire pas encore un prochain token.
