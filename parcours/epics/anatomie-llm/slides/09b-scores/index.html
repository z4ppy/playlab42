1 · AVANT DE MANIPULER

Comprendre le mécanisme.

La sortie du modèle attribue un score, appelé logit, à chaque token du vocabulaire. Ces scores peuvent être négatifs et leur somme n’a pas de valeur particulière. Ce sont leurs écarts qui comptent : un candidat au score plus grand reçoit davantage de probabilité après conversion.

Le softmax transforme les scores en nombres positifs dont la somme vaut 1. Il amplifie les écarts par une exponentielle puis divise par le total. Dans cette étape, trois scores choisis à la main permettent de voir cette transformation, sans confondre ce petit exemple avec la sortie d’un modèle entraîné.

Un repère numérique : les scores [0 ; 0 ; 0] donnent environ [33,3 % ; 33,3 % ; 33,3 %]. [1 ; 1 ; 1] donne exactement les mêmes probabilités : ajouter une constante à tous les scores ne change pas leurs écarts. Dans Luciole, la sortie contient 333 scores, un par entrée du vocabulaire.

Une distribution n’est toujours pas un choix. On peut prendre son maximum ou tirer un candidat au hasard selon les probabilités obtenues. L’étape « Le tirage » applique ces stratégies à cinq candidats fictifs pour rendre leurs effets visibles ; le laboratoire les utilise avec les vrais scores de Luciole. Une probabilité élevée n’est pas une garantie de vérité.

Facultatif · formule softmax

probabilité(i) = exp(scoreᵢ) / somme des exp(scores). On retire en pratique le score maximal avant l’exponentielle pour stabiliser le calcul, sans changer le résultat.

Dans le code de Luciole · Stabiliser softmax sans changer les probabilités

Soustraire le maximum avant exp évite de calculer des exponentielles trop grandes. Chaque valeur est divisée par le total. La température règle la concentration ; la branche temperature === 0 sélectionne directement le premier maximum.

  const max = Math.max(...logits);
  if (temperature === 0) { return logits.map((_, i) => Number(i === logits.indexOf(max))); }
  const exp = logits.map(v => Math.exp((v - max) / temperature));
  const sum = exp.reduce((s, v) => s + v, 0);
  return exp.map(v => v / sum);
}

3 · VÉRIFIER SA COMPRÉHENSION

Si les trois scores sont égaux, quelles probabilités softmax obtient-on ?

Lire la correction

Un tiers pour chacun. Des scores identiques ont les mêmes exponentielles ; chacun reçoit donc un tiers du total.
