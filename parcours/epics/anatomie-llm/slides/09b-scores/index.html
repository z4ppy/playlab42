À la sortie des blocs, le modèle produit un score par token du vocabulaire. Ces scores peuvent être négatifs et ne totalisent rien de particulier : il faut les convertir en probabilités.

1 · AVANT DE MANIPULER

Comprendre le mécanisme.

Des scores bruts : les logits

Une dernière projection transforme le vecteur du dernier token en une liste de scores, un par entrée du vocabulaire : 333 pour Luciole, des dizaines de milliers pour un grand modèle. Ces scores s’appellent des logits. Seuls leurs écarts comptent : un logit de 3 face à 0 signifie « nettement plus probable », quelle que soit la valeur absolue.

La conversion : softmax

Softmax fait deux choses : il rend chaque score positif en prenant son exponentielle, puis divise par le total pour que tout fasse 100 %. L’exponentielle amplifie les écarts : un point de score en plus multiplie la probabilité relative par environ 2,7.

Exemple chiffré : les scores [−2 ; 0 ; 3] donnent environ [0,6 % ; 4,7 % ; 94,7 %]. Les scores [0 ; 0 ; 0] donnent un tiers chacun, tout comme [5 ; 5 ; 5] : ajouter la même constante à tous les scores ne change rien.

Une probabilité n’est pas encore un choix

Le modèle fournit une distribution ; il reste à choisir un token. On peut prendre le plus probable ou tirer au hasard selon ces probabilités. C’est l’objet de l’étape suivante. Notez aussi qu’une probabilité élevée exprime ce qui est fréquent dans la continuité des données d’entraînement, pas une garantie de vérité.

Pour les avertis · formule et stabilité numérique

pi = exp(zi) / Σj exp(zj). En pratique, on soustrait max(z) avant l’exponentielle pour éviter les débordements, sans changer le résultat. Le logarithme de pi sert directement de perte à l’entraînement (entropie croisée).

Dans le code de Luciole · Stabiliser softmax sans changer les probabilités

Soustraire le maximum avant exp évite de calculer des exponentielles trop grandes. Chaque valeur est divisée par le total. La température règle la concentration ; la branche temperature === 0 sélectionne directement le premier maximum.

  const max = Math.max(...logits);
  if (temperature === 0) { return logits.map((_, i) => Number(i === logits.indexOf(max))); }
  const exp = logits.map(v => Math.exp((v - max) / temperature));
  const sum = exp.reduce((s, v) => s + v, 0);
  return exp.map(v => v / sum);
}

À RETENIR

Logits, probabilités et choix sont trois étapes distinctes. Softmax convertit des scores en probabilités en amplifiant leurs écarts.

LES LIMITES

Les trois scores de cette étape sont choisis à la main pour isoler le calcul ; ce n’est pas une sortie de Luciole. Une probabilité élevée n’est pas un certificat de vérité.

Le vocabulaire de cette étape
logits
Scores non normalisés produits avant la conversion en probabilités.
softmax
Transforme des scores quelconques en nombres positifs dont la somme vaut 1 : une distribution de probabilités.
décodage
Procédure qui choisit les tokens à partir des scores du modèle : choix du maximum ou tirage après application de filtres.

3 · VÉRIFIER SA COMPRÉHENSION

Si les trois scores sont égaux, quelles probabilités softmax donne-t-il ?

Lire la correction

Un tiers pour chacun. Des scores identiques ont la même exponentielle ; chacun reçoit donc un tiers, quelle que soit leur valeur commune.
