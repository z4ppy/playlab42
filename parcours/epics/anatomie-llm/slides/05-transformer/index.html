1 · AVANT DE MANIPULER

Comprendre le mécanisme.

L’attention combine l’information de plusieurs positions. Le MLP, petit réseau de neurones, transforme ensuite chaque position, avec les mêmes poids pour tous les tokens. Pensez à deux gestes : mélanger entre les tokens, puis transformer chaque liste séparément. Ce sont des calculs, pas des intentions. Empiler ces blocs permet de construire des représentations plus élaborées.

Les connexions résiduelles ajoutent le résultat d’une transformation à son entrée. Elles offrent un chemin direct à l’information et aux gradients. La normalisation contrôle l’échelle des activations ; elle ne convertit pas les valeurs en probabilités.

Luciole utilise deux blocs, quatre têtes et un MLP dense 32 → 64 → 32. « Dense » signifie que ce réseau entier est utilisé pour chaque token, sans routeur d’experts. Les positions sont des vecteurs appris, pas RoPE.

2017 : une machine à traduire. L’article fondateur du Transformer présentait un encodeur et un décodeur pour la traduction. Ici, nous suivons un décodeur causal : une branche de cette famille, adaptée à la continuation de texte. De nombreux modèles actuels changent la normalisation, le MLP ou l’attention ; certains combinent même d’autres types de couches.

Facultatif · noms et ordre exact des opérations

Luciole est pré-normalisé : RMSNorm sans gain appris avant l’attention et le MLP ; ReLU remplace les valeurs négatives par zéro entre les deux projections du MLP. Les résidus ajoutent les sorties à leurs entrées. x ← x + Attention(Norm(x)), puis x ← x + MLP(Norm(x)). Ce n’est pas le plan unique de tous les LLM.

Dans le code de Luciole · Attention, résidu, puis MLP

attended.result réunit les sorties des têtes ; la matrice o les projette. Le premier add forme le résidu après attention. up élargit 32 nombres à 64, relu met les négatifs à zéro, down revient à 32, et le second add ajoute le résultat au résidu.

    const attended = attention(q, k, v, config.heads);
    const residual = add(x, matmul(attended.result, weights[`${i}.o`]));
    const hidden = relu(matmul(rmsnorm(residual), weights[`${i}.up`]));
    x = add(residual, matmul(hidden, weights[`${i}.down`]));

LES LIMITES

L’image « des couches qui pensent de plus en plus » est une métaphore, pas une description mesurée.

Le vocabulaire de cette étape
bloc
Étape répétée du Transformer : mélanger les informations avec l’attention, puis transformer chaque vecteur avec un MLP.
tête
Un des calculs d’attention effectués en parallèle dans un bloc. Dans Luciole, chaque tête possède ses matrices de projection pour Q, K et V.
q/k/v
Query, Key, Value : requête, clé, valeur. Q et K déterminent les proportions du mélange ; V fournit les nombres à mélanger.
rmsnorm
Opération qui remet les nombres d’un vecteur à une échelle comparable, sans les transformer en probabilités.
concaténation
Mise bout à bout de listes de nombres. Les sorties des quatre têtes de Luciole sont réunies avant une nouvelle projection.
résidu
Chemin qui ajoute l’entrée d’un sous-bloc à sa sortie, à dimensions compatibles.
mlp
Petit réseau de neurones qui transforme les nombres de chaque token, sans consulter directement les autres positions.
relu
Fonction qui garde les nombres positifs et remplace les nombres négatifs par zéro : max(0, x).

3 · VÉRIFIER SA COMPRÉHENSION

Quelle opération mélange directement les informations de plusieurs positions ?

Lire la correction

L’attention. L’attention calcule une combinaison des valeurs d’autres positions. Le MLP standard agit séparément sur chaque ligne.
