1 · AVANT DE MANIPULER

Comprendre le mécanisme.

Un passage complet

Quand vous cliquez sur « + Un token », Luciole effectue un passage avant : découper le prompt, lire les embeddings, ajouter les positions, traverser les deux blocs d’attention et de MLP, normaliser, projeter vers 333 scores, puis tirer un token. Toutes les vues du laboratoire — tokens, vecteurs, blocs, attention, candidats — décrivent ce même calcul.

Retrouver chaque étape du parcours

  • Tokens : le découpage de l’étape 3, avec ses numéros.
  • Vecteurs : l’embedding plus la position, avant tout échange entre tokens.
  • Bloc 1, Bloc 2 : le même token après chaque bloc, enrichi par le contexte.
  • Couche et tête inspectées : la grille d’attention de l’étape 9 pour le calcul en cours.
  • Sortie : les probabilités avant et après les réglages de décodage.

Mener une petite enquête

Partez de « la capitale de la france est », puis remplacez seulement « france » par « belgique ». Comparez dans l’ordre : les tokens d’entrée, la dernière ligne d’attention, puis les candidats. Ne changez qu’une chose à la fois, sinon vous ne saurez pas ce qui a produit la différence. La température est réglée par défaut à 0,7 : la génération tire au hasard, avec la graine 42 pour que le résultat soit reproductible.

Vous pouvez composer vos propres prompts avec les mots du corpus, jusqu’à 32 tokens. Un mot inconnu est signalé, jamais remplacé en silence. « ← Revenir » inspecte l’état précédent ; « Réinitialiser » restaure le prompt et la graine.

Dans le code de Luciole · La sortie et les traces du même passage avant

traces garde les états, les Q/K/V et les cartes d’attention réellement calculés. La sortie utilise RMSNorm puis la matrice output. L’interface lit la dernière ligne des logits pour choisir le prochain token ; elle ne remplace pas le calcul par une réponse écrite à l’avance.

    traces.push({ state: x, attention: attended.maps, q, k, v, hidden });
  }
  return { logits: matmul(rmsnorm(x), weights.output), traces };
}

À RETENIR

Toutes les vues décrivent un même calcul réel. Les mécanismes sont inspectables ; la qualité des réponses dépend aussi des données, de l’échelle et de l’entraînement.

LES LIMITES

Luciole est un modèle pédagogique, pas un assistant : pas de RoPE, de MoE, de GQA ni de KV cache. Deux exemples ne suffisent pas à démontrer une connaissance générale des capitales.

Le vocabulaire de cette étape
passage avant
Exécution des calculs depuis les tokens d’entrée jusqu’aux scores de sortie, sans modifier les poids.
bloc
Étape répétée du Transformer : mélanger les informations avec l’attention, puis transformer chaque vecteur avec un MLP.
tête
Un des calculs d’attention effectués en parallèle dans un bloc. Dans Luciole, chaque tête possède ses matrices de projection pour Q, K et V.
q/k/v
Query, Key, Value : requête, clé, valeur. Q et K déterminent les proportions du mélange ; V fournit les nombres à mélanger.
décodage
Procédure qui choisit les tokens à partir des scores du modèle : choix du maximum ou tirage après application de filtres.
graine
Valeur initiale d’un générateur pseudo-aléatoire. Même graine et mêmes réglages permettent de reproduire les tirages.

3 · VÉRIFIER SA COMPRÉHENSION

Les probabilités du laboratoire sont-elles prédéfinies pour chaque phrase ?

Lire la correction

Non, elles résultent du calcul avec les poids publiés. Le calcul s’exécute dans votre navigateur avec les poids appris de Luciole ; aucune réponse n’est écrite à l’avance.
