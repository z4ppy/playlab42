1 · AVANT DE MANIPULER

Comprendre le mécanisme.

Le laboratoire réunit le tokenizer lexical, les embeddings, les positions apprises, les deux blocs d’attention et MLP, la normalisation, la projection et le tirage. Les paramètres chargés sont les poids réellement entraînés et publiés.

Choisissez un exemple ou composez un prompt avec le vocabulaire disponible. La fenêtre est limitée à 32 tokens, marqueur de début compris. Un mot inconnu est signalé, pas silencieusement remplacé. « Revenir » permet d’inspecter l’état précédent ; « Réinitialiser » restaure le prompt et la graine.

Les vues attention, représentation et candidats correspondent toutes au même passage avant. Le calcul est entièrement local. Pour garder le code lisible, Luciole recalcule le contexte et n’implémente pas de KV cache.

Une enquête simple : changez seulement « france » en « belgique », en gardant les réglages fixes. Comparez d’abord les tokens d’entrée, puis la dernière ligne d’attention et les candidats. Vous observez l’effet de cette modification sur ce modèle ; deux exemples ne suffisent pas à démontrer une connaissance générale des capitales.

Dans le code de Luciole · La sortie et les traces du même passage avant

traces garde les états, les Q/K/V et les cartes d’attention réellement calculés. La sortie utilise RMSNorm puis la matrice output. L’interface lit la dernière ligne des logits pour choisir le prochain token ; elle ne remplace pas le calcul par une réponse écrite à l’avance.

    traces.push({ state: x, attention: attended.maps, q, k, v, hidden });
  }
  return { logits: matmul(rmsnorm(x), weights.output), traces };
}

À RETENIR

Les mécanismes sont inspectables. La qualité des réponses dépend aussi des données, de l’échelle et de l’entraînement.

LES LIMITES

Luciole est un modèle pédagogique, pas un assistant. Pas de RoPE, MoE, GQA ou KV cache dans ce mini-modèle ; ces variantes sont étudiées séparément.

Le vocabulaire de cette étape
passage avant
Exécution des calculs depuis les tokens d’entrée jusqu’aux scores de sortie, sans modifier les poids.
bloc
Étape répétée du Transformer : mélanger les informations avec l’attention, puis transformer chaque vecteur avec un MLP.
tête
Un des calculs d’attention effectués en parallèle dans un bloc. Dans Luciole, chaque tête possède ses matrices de projection pour Q, K et V.
q/k/v
Query, Key, Value : requête, clé, valeur. Q et K déterminent les proportions du mélange ; V fournit les nombres à mélanger.
décodage
Procédure qui choisit les tokens à partir des scores du modèle : choix du maximum ou tirage après application de filtres.
graine
Valeur initiale d’un générateur pseudo-aléatoire. Même graine et mêmes réglages permettent de reproduire les tirages.

3 · VÉRIFIER SA COMPRÉHENSION

Les probabilités montrées dans le laboratoire sont-elles prédéfinies pour chaque phrase ?

Lire la correction

Non, elles résultent du calcul avec les poids publiés. Le graphe numérique est exécuté localement. Les mêmes opérations servent à son entraînement et à son inférence.
