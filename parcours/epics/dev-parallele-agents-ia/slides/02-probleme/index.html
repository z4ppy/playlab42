⚠️ Le problème à résoudre

Plusieurs tâches en parallèle, avec ou sans agent

Même sans IA, le problème existe. Vous travaillez sur une feature, un bug urgent arrive, vous devez switcher.

😓 Solutions classiques

  • git stash — fragile, facile à perdre
  • Plusieurs clones du repo — lourd en disque, synchronisation manuelle
  • Branches et checkout constants — perte de contexte, rebuilds

🤖 Avec des agents IA, ça empire

Si vous lancez plusieurs agents (Claude Code, Codex, Aider…) dans le même répertoire que votre travail en cours :

  • Écritures simultanées sur les mêmes fichiers
  • Une seule staging area : chacun commite les fichiers des autres
  • Builds et tests qui s'interfèrent
  • Modifications écrasées ou mélangées, impossibles à attribuer

🎯 Ce qu'il nous faut

Chaque tâche — qu'elle soit manuelle ou confiée à un agent — a besoin de :

  • Son propre répertoire de travail
  • Son propre état Git (index, HEAD)
  • Une synchronisation simple avec le repo principal
C'est exactement ce que permet Git Worktree
