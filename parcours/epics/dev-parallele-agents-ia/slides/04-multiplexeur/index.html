🖥️ Superviser plusieurs agents : le multiplexeur terminal

Pour suivre plusieurs agents lancés dans des terminaux, il faut les voir côte à côte et pouvoir les laisser tourner quand on ferme la fenêtre. C'est le rôle du multiplexeur.

✅ tmux (recommandé)

Par défaut, le préfixe est Ctrl-B ; % coupe en gauche/droite et " en haut/bas. Une configuration minimale pour le multi-agents :

# ~/.tmux.conf
# Préfixe plus accessible
set -g prefix C-a
unbind C-b
bind C-a send-prefix

# Souris et historique étendu
set -g mouse on
set -g history-limit 50000

# Découpages mnémotechniques, ouverts dans le dossier du panneau courant
bind | split-window -h -c "#{pane_current_path}"
bind - split-window -v -c "#{pane_current_path}"

# Quatre panneaux d'un coup
bind A split-window -h \; split-window -v \; select-pane -t 0 \; split-window -v

# Activer/désactiver la saisie synchronisée dans tous les panneaux
bind S setw synchronize-panes
Raccourci (avec cette configuration)Action
Ctrl-A | / Ctrl-A -Couper gauche/droite, haut/bas
Ctrl-A ACréer quatre panneaux
Ctrl-A + flèchesChanger de panneau
Ctrl-A SSynchroniser la saisie (à manier avec prudence)
Ctrl-A dSe détacher : les agents continuent
tmux attachSe rattacher

Claude Code sait ouvrir lui-même une session tmux pour un worktree : claude -w feature-auth --tmux.

📟 GNU Screen (si tmux n'est pas disponible)

screen -S agents       # nouvelle session
screen -r agents       # se rattacher
# Ctrl-A c : nouveau terminal · Ctrl-A n / p : suivant / précédent
# Ctrl-A " : liste des terminaux · Ctrl-A d : se détacher

🦎 Zellij (alternative moderne)

Configuration déclarative en KDL. Les arguments d'une commande se placent dans un bloc enfant du panneau :

# ~/.config/zellij/layouts/agents.kdl
layout {
    tab name="Agent-auth" cwd="/home/moi/projets/mon-projet-agent-auth" {
        pane command="claude"
    }
    tab name="Agent-api" cwd="/home/moi/projets/mon-projet-agent-api" {
        pane command="claude"
    }
    tab name="Suivi" cwd="/home/moi/projets/mon-projet" {
        pane command="watch" {
            args "-n" "5" "git worktree list"
        }
    }
}

Lancement : zellij --layout agents. Préférez des chemins absolus pour cwd.

🎮 Outils d'orchestration dédiés

Ces outils combinent worktrees et sessions d'agents dans une seule interface :

OutilPrincipeDémarrer
Claude Squad Interface terminal : une session tmux et un worktree par agent (Claude Code, Codex, Gemini, Aider…). cs · cs -p "codex"
git-worktree-runner (CodeRabbit) Commande git gtr : crée le worktree, prépare la branche et lance l'outil d'IA choisi. git gtr new feature/auth
git gtr ai feature/auth --ai aider
CCManager Gestion de sessions d'agents par worktree, sans tmux, avec l'état de chaque session (occupée, en attente…). npx ccmanager
Conductor Application macOS : agents Claude Code, Codex ou Cursor dans des espaces isolés (un worktree chacun), avec revue des diffs. Une offre cloud est aussi annoncée. Téléchargement depuis le site

Installation de Claude Squad : brew install claude-squad (puis créer l'alias cs comme indiqué dans le README) ou le script d'installation du dépôt. Ces outils évoluent vite : vérifiez leur README avant une session de formation.

Sources (consultées le 8 novembre 2026) : manuel tmux, layouts Zellij, worktrees Claude Code, README des outils cités.
