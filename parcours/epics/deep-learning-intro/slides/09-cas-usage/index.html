Cette page explore les applications concrètes qui transforment notre quotidien.

Vision par Ordinateur

La vision par ordinateur est le domaine où le deep learning a eu l'impact le plus spectaculaire. Depuis AlexNet (2012), les réseaux convolutifs ont révolutionné la reconnaissance d'images.

Reconnaissance faciale

Apple Face ID

Depuis l'iPhone X (2017), un scanner 3D analyse 30 000+ points de votre visage. Fonctionne dans le noir, avec des lunettes, même si vous changez de coiffure.

→ Documentation Apple
Amazon Rekognition

API cloud pour identifier visages, objets, texte, scènes. Utilisé par la police (controversé), le retail, et les médias.

→ AWS Rekognition

Véhicules autonomes

🇺🇸 Tesla — Vision pure

8 caméras, pas de LiDAR. Architecture IA end-to-end qui remplace le code modulaire. Objectif : millions de véhicules autonomes.

Avantage : coût réduit. Risque : robustesse dans conditions extrêmes.

🇺🇸 Waymo — Multi-capteurs

29 caméras + 5 LiDAR + RADAR. 250 000+ trajets/semaine à Phoenix, San Francisco, Los Angeles. Architecture EMMA (End-to-End).

→ Waymo Research
🇨🇳 Baidu Apollo Go

17M+ trajets, 240M km, 22 villes. 100% sans conducteur depuis février 2025. Plus grand service robotaxi au monde.

Partenariat CATL pour batteries et châssis.

→ Apollo Auto

Traitement du Langage Naturel

Le NLP a connu une révolution avec les Transformers (2017). Aujourd'hui, les LLM comme ChatGPT ou Claude peuvent écrire, traduire, résumer, coder, et converser naturellement.

Traduction automatique

Google Translate

249 langues. Des milliards de traductions par jour. Architecture : encodeur Transformer + décodeur RNN (depuis 2020).

→ translate.google.com
DeepL

37 langues, mais qualité supérieure selon les experts. 82% des traducteurs pro utilisent DeepL (ALC 2024). Basé Transformers.

→ deepl.com

→ mistral.ai

Assistants vocaux

Siri, Alexa, Google Assistant utilisent tous un pipeline : ASR (parole → texte) + NLP (compréhension) + TTS (synthèse vocale). Les RNN détectent "Hey Siri", les Transformers comprennent l'intention.

Analyse de sentiment

Les LLMs analysent les émotions dans le texte : positif, négatif, neutre, avec intensité. Applications :

  • • Brand24 — Monitoring de marque en temps réel
  • • Crowd Analyzer — Spécialiste de l'arabe et du sarcasme
  • • John Snow Labs — État de l'art en NLP médical

Systèmes de Recommandation

Les algorithmes de recommandation génèrent des milliards de dollars de revenus. Ils combinent filtrage collaboratif ("les gens comme vous aiment...") et deep learning pour modéliser vos préférences.

Netflix

75-80% des heures de visionnage viennent des recommandations. 300M+ utilisateurs. Économie : $1 Md/an en réduction du churn.

Tech : Foundation models, RNN/LSTM, VAEs, multi-task learning.

→ Netflix Tech Blog
Spotify

Discover Weekly : 30 morceaux personnalisés chaque lundi. 50M de morceaux, 4 Mds de playlists. CNN sur spectrogrammes audio.

Tech : CNN, RNN, reinforcement learning, collaborative filtering.

→ Spotify Engineering
YouTube

Modèle à 1 milliard de paramètres. 2 étapes : génération de candidats → classement. Défis : échelle, fraîcheur, équilibre nouveauté/popularité.

→ Google Research Paper
Amazon

Pionnier du "item-to-item collaborative filtering" (1998). LSTM/GRU pour les séquences d'achat. 35% du chiffre d'affaires via recommandations.

→ Amazon Science
🇨🇳
TikTok — L'algorithme le plus addictif au monde

1,5 milliard d'utilisateurs actifs. ByteDance a investi $20 Mds en 2025 dans son infrastructure IA. Contrairement aux autres réseaux sociaux, TikTok ne recommande pas selon votre graphe social, mais selon vos intérêts.

  • • 30-50% de vidéos ciblant vos intérêts connus, le reste pour explorer
  • • Adaptation en temps réel aux préférences selon l'heure de la journée
  • • Architecture propriétaire : "Monolith" avec embeddings sans collision
→ TikTok Algorithm Deep Dive

Jeux & Découvertes Scientifiques

Les jeux ont été un terrain d'expérimentation privilégié pour le deep learning. Les mêmes techniques révolutionnent maintenant la recherche scientifique.

AlphaGo (2016)

DeepMind bat Lee Sedol au Go (4-1), regardé par 200 millions de personnes. Le Go a 10170 configurations possibles.

Architecture : Policy Network + Value Network + Monte Carlo Tree Search.

→ DeepMind AlphaGo
OpenAI Five (2019)

Bat les champions du monde de Dota 2. 180 ans de parties/jour en self-play. 256 GPUs, 128K CPU cores. 99,4% de victoires.

Tech : LSTM 4096 unités, 150M paramètres, PPO massivement parallélisé.

→ OpenAI Five
🧬
AlphaFold — Prix Nobel 2024

200+ millions de structures protéiques prédites. Utilisé par 3,5M de chercheurs dans 190 pays. Demis Hassabis et John Jumper reçoivent le Nobel de chimie.

  • • AlphaFold 2 (2020) : Précision atomique sur le problème du "protein folding"
  • • AlphaFold 3 (2024) : Complexes protéiques avec ADN, ARN, modifications
→ DeepMind AlphaFold

Finance & Trading

Trading algorithmique

Renaissance Technologies

Medallion Fund : ~66% de rendement annuel avant frais (1988-2018). Fondé par Jim Simons (mathématicien). ML propriétaire + NLP sur actualités.

Two Sigma

Analyse les minutes de la Fed avec du NLP pour prédire les taux. Modèles qui apprennent et s'adaptent en continu. Big data + ML.

Détection de fraude

90% des banques mondiales utilisent l'IA/ML pour détecter la fraude. Marché : $17,9 Mds (2025) → $60,6 Mds (2033).

  • • Technologies : CNN, LSTM, Transformers, Graph Neural Networks, Autoencoders
  • • Applications : Transactions suspectes, identités synthétiques, phishing, deepfakes
  • • Défi : 50%+ des fraudes utilisent maintenant l'IA elles-mêmes

Santé & Pharmaceutique

Le deep learning accélère la découverte de médicaments, le diagnostic, et la médecine personnalisée. Les laboratoires "autonomes" combinent robotique et IA.

Découverte de médicaments

Insilico Medicine

Phase IIa positive pour ISM001-055 (fibrose pulmonaire). Premier médicament "AI-native" en essais cliniques avancés.

Recursion + Exscientia

Fusion créant une plateforme end-to-end : screening phénomique + chimie de précision automatisée.

Atomwise

Premier réseau de neurones pour la découverte structure-based de médicaments. Milliards de molécules criblées virtuellement.

AstraZeneca

Analyse de 2 millions de séquences génomiques d'ici 2026 pour identifier de nouvelles cibles thérapeutiques.

Technologies clés : Graph Neural Networks pour les molécules, Transformers pour les protéines, reinforcement learning pour l'optimisation de leads.

Robotique & Automatisation

L'IA "embodied" — c'est-à-dire incarnée dans un corps physique — est le prochain grand défi. Marché : $4,4 Mds (2025) → $23 Mds (2030).

Tesla Optimus

Robot humanoïde pour tâches dangereuses, ennuyeuses, répétitives. Prix cible : $20-30K. Production de masse prévue 2026.

Utilise la même IA de vision que les voitures Tesla.

Boston Dynamics Atlas

Démonstrations spectaculaires : backflips, parkour. Version électrique (2024). Pilotes avec Hyundai en usine automobile.

→ Boston Dynamics Atlas

Art & Créativité Générative

L'IA générative transforme la création artistique. 78% des producteurs professionnels utilisent au moins un générateur IA. Réduction du temps de production : 62% en moyenne.

Génération d'images

Midjourney

Standard d'or pour la qualité artistique. Rendu "cinématographique". 50M+ créateurs sur les plateformes principales.

→ midjourney.com
DALL-E 3

OpenAI. Excellent en compréhension du langage naturel. Peut écrire du texte dans les images. Intégré à ChatGPT.

→ openai.com/dall-e-3
Stable Diffusion

Open-source. Exécution locale possible. Centaines de modèles spécialisés (anime, architecture...).

→ stability.ai

Génération musicale

Suno

12M+ utilisateurs actifs. Valorisation : $2,45 Mds (Série C, nov 2025). Génère des chansons complètes à partir d'un prompt texte.

Controversé : poursuivi par les labels pour droits d'auteur.

→ suno.ai
OpenAI Jukebox (2020)

Génération de musique en audio brut avec paroles. Discontinué mais historique. OpenAI développe un nouvel outil musical (2025).

→ OpenAI Jukebox

Fait marquant : 28% des morceaux uploadés sur Deezer sont entièrement générés par IA (septembre 2024).

Ce qu'il faut retenir

  • • Le deep learning est partout : téléphone, streaming, voiture, hôpital, banque
  • • Les mêmes techniques (CNN, Transformers, RL) s'appliquent à des domaines très différents
  • • Les géants tech investissent des milliards, mais les startups innovent aussi (Suno, Insilico...)
  • • Les enjeux éthiques et réglementaires sont majeurs (deepfakes, biais, emploi)
  • • AlphaFold a montré que le deep learning peut résoudre des problèmes scientifiques fondamentaux
