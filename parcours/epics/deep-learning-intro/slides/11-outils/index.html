Les Frameworks de Deep Learning

Un framework fournit les briques de base : tenseurs, autograd, optimiseurs, couches pré-construites. Le choix du framework dépend de votre cas d'usage : recherche, production, ou les deux.

Framework Éditeur Usage recherche Usage production Force
PyTorch Meta ~85% ~25% Recherche, flexibilité
TensorFlow Google ~10% ~38% Production, mobile
JAX Google ↗ 5% ↗ Performance, TPU
Keras Indépendant — ~17% Simplicité, multi-backend

Note : "Usage recherche" = % des papers ML publiés. "Usage production" = part de marché dans les déploiements entreprise. PyTorch domine la recherche (85%), TensorFlow domine la production (38%).

PyTorch — Le favori des chercheurs

Pourquoi PyTorch domine la recherche
  • • Python-first : code naturel, débugage facile
  • • Eager execution : résultats immédiats
  • • 85% des papers ML l'utilisent
  • • GPT, Llama, Stable Diffusion = PyTorch
Chiffres clés
  • • 72 000 étoiles GitHub
  • • 17 000+ entreprises utilisatrices
  • • torch.compile() : +25% perf gratuit
  • • Domaine : NLP, génératif, vision
exemple_pytorch.py 
import torch
import torch.nn as nn

# Définir un réseau simple
class MLP(nn.Module):
    def __init__(self):
        super().__init__()
        self.layers = nn.Sequential(
            nn.Linear(784, 128),
            nn.ReLU(),
            nn.Linear(128, 10)
        )

    def forward(self, x):
        return self.layers(x)

# Entraînement en 3 lignes
model = MLP().cuda()  # GPU
optimizer = torch.optim.Adam(model.parameters())
loss_fn = nn.CrossEntropyLoss()

JAX & Autres Frameworks

JAX — Performance maximale

Développé par Google, JAX est un "NumPy accéléré" avec différentiation automatique et compilation JIT via XLA. Paradigme fonctionnel pur.

Avantages

  • • Plus rapide que TF/PyTorch sur GPU/TPU
  • • Idéal pour calcul scientifique
  • • Croissance rapide en recherche

Inconvénients

  • • Courbe d'apprentissage raide
  • • Moins de modèles pré-entraînés
  • • Écosystème moins mature

→ jax.readthedocs.io

🤗 Hugging Face

130 000+ modèles pré-entraînés. Compatible PyTorch, TF, JAX. Le hub de l'IA open-source.

huggingface.co
⚡ Lightning

Surcouche PyTorch qui élimine le boilerplate. Training distribué simplifié.

lightning.ai
📦 ONNX

Format universel d'échange. Convertir PyTorch → TF → mobile. Jusqu'à 5x plus rapide.

onnx.ai

Alternatives : TPU, AMD, Apple

Google TPU — Conçu pour les Transformers

Les TPU (Tensor Processing Units) sont des ASIC optimisés pour les opérations matricielles. Exclusifs à Google Cloud.

TPU v7 (Ironwood) — 2025

  • • 4 614 TFLOPS BF16 (10x vs v5p)
  • • 100% meilleur perf/watt vs v6
  • • Pods jusqu'à 9 216 chips

Clients majeurs

  • • Anthropic (Claude)
  • • Midjourney
  • • Salesforce, Snap

→ cloud.google.com/tpu

AMD Instinct — Le challenger mémoire

AMD mise sur la capacité mémoire pour les très grands modèles. MI300X : 192 GB vs 80 GB pour le H100.

MI350X (juin 2025)

ROCm — Le "CUDA d'AMD"

  • • Open-source

GPU dans le Cloud

Pas besoin d'acheter un GPU à $30K : les cloud providers louent des instances GPU à l'heure. Les "NeoClouds" offrent souvent de meilleurs prix que les Big 3.

Provider H100 (8x) A100 Spécificité
AWS ~$55/h ~$22/h (8x) Leader, intégration services
GCP ~$29/h spot ~$17/h spot (8x) TPU exclusifs, Vertex AI
Azure Variable ~$3-12/h (4x V100) InfiniBand 200 Gbps
Lambda Labs $2.49-3.29/h $1.29/h Meilleur rapport qualité/prix

Conseils pour économiser

  • • Spot/Preemptible : jusqu'à 90% de réduction (mais interruptible)
  • • NeoClouds (Lambda, CoreWeave, Vast.ai) : 50-70% moins cher que Big 3
  • • Engagements courts : 1 an max (la techno IA évolue trop vite)
  • • Google Colab : gratuit pour débuter (T4), Pro à $10/mois
