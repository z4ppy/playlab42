🗺️ Panorama au 8 novembre 2026

En 2025, on classait les outils par forme : IDE, extension, CLI. En 2026, cette grille ne tient plus : les principaux éditeurs proposent le même agent sur plusieurs surfaces (terminal, éditeur, application de bureau, web) et presque tous peuvent le faire tourner dans le cloud. La vraie question devient : quel agent, avec quels modèles, à quel coût, et où s'exécute-t-il ?

L'éditeur Zed (licence GPL-3.0) illustre une autre tendance : il accueille des agents externes grâce à l'Agent Client Protocol (ACP), comme un éditeur accueille un serveur de langage.

Une année de consolidation

  • 14 juillet 2025 : Cognition (Devin) rachète Windsurf, renommé Devin Desktop le 2 juin 2026.
  • 2 décembre 2025 : Amp quitte Sourcegraph et devient une société indépendante.
  • 3 décembre 2025 : Anthropic rachète le runtime JavaScript Bun « pour accélérer Claude Code », qui atteint alors un milliard de dollars de revenu annualisé six mois après sa disponibilité générale.
  • 30 avril 2026 : AWS annonce la fin de support d'Amazon Q Developer dans les IDE et oriente vers Kiro.
  • 15 mai 2026 : l'extension Roo Code est arrêtée et son dépôt archivé.
  • Mai-juin 2026 : Google fait passer les utilisateurs de Gemini CLI vers Antigravity CLI.
  • Juin 2026 : Cursor rachète Continue, qui cesse son activité.
  • 30 juillet 2026 : Tricentis rachète Tabnine.
  • 14 août 2026 : Cursor rejoint SpaceX.

Conséquence pour une équipe : un outil peut changer de nom, de propriétaire ou de modèle économique en quelques mois. Gardez ce qui est portable : des conventions dans AGENTS.md, des specs versionnées, des intégrations via des standards ouverts (MCP, Agent Skills) plutôt que via des fonctions propres à un outil.

Du forfait à l'usage

Les agents consomment beaucoup plus de tokens qu'une autocomplétion. Les éditeurs ont donc remplacé les requêtes « illimitées » par des enveloppes mesurées : Cursor a basculé vers une enveloppe d'usage en juin 2025, GitHub Copilot facture en AI Credits au token depuis le 1er juin 2026, Claude Code applique des limites par fenêtre de 5 heures et par semaine, Kiro et Junie comptent en crédits.

Pour une équipe, le budget se raisonne désormais par tâche, pas seulement par licence.

Comment choisir ?

CritèreQuestion à poser
DonnéesOù part le code ? Quelles garanties de non-rétention et de localisation ?
ModèlesUn seul fournisseur, ou le choix du modèle par tâche ?
ExécutionEn local, en bac à sable, dans le cloud de l'éditeur ou sur votre infrastructure ?
CoûtAbonnement, crédits ou API : combien coûte une tâche typique de votre équipe ?
PortabilitéLit-il AGENTS.md, les Agent Skills et MCP ? Peut-on en changer sans tout réécrire ?
