Les chiffres de 2025 à corriger

  • « 41 % du code généré par IA en 2024 » : aucune source primaire retrouvée.
  • « 40 % du code Microsoft via Copilot » : non confirmé par une source primaire ; à ne pas citer.
  • « 20 % de 756 000 échantillons recommandent des paquets inexistants » : l'étude porte sur 576 000 échantillons, et les 19,7 % concernent les paquets suggérés, pas les échantillons (voir le chapitre sécurité).
  • « 77,2 % sur SWE-bench Verified » : un score annoncé par l'éditeur, sur un benchmark aujourd'hui délaissé pour cause de contamination (voir le chapitre mesures).

Leçon de méthode : les tendances de fond (standards ouverts, autonomie, specs) se sont confirmées ; les chiffres précis, souvent repris de seconde main, étaient fragiles. Pour un support de cours, une statistique sans source primaire n'a pas sa place.
