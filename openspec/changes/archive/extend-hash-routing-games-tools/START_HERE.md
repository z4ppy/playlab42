## ❓ Questions Rapides

### Q: C'est quoi cette proposition?

**A:** Ajouter des liens partageables aux jeux/outils, comme les épics les ont déjà:
- `#/games/tictactoe` → ouvre directement le jeu
- `#/tools/json-formatter` → ouvre directement l'outil

### Q: Combien ça prend de temps?

**A:** ~4 jours (5 phases de 1-2 jours chacune)

### Q: C'est risqué?

**A:** Non, risque bas. Pas de breaking changes. Réutilise le router existant.

### Q: Et pour Open Graph (Teams/Slack)?

**A:** Exploration séparée, post-MVP. Voir [specs/og-metadata-future/spec.md](./specs/og-metadata-future/spec.md)
