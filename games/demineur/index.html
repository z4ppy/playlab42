    Commandes et règles

    Ouvrez toutes les cases sans mine. Un chiffre compte les mines parmi ses huit voisines. Souris : clic pour ouvrir, clic droit pour un drapeau, clic sur un chiffre (ou clic milieu) pour ouvrir ses voisines quand ses drapeaux sont posés. Doigt : appui pour ouvrir, appui long ou mode drapeau pour marquer. Clavier : flèches pour se déplacer, Entrée ou Espace pour ouvrir, F pour un drapeau, H pour un indice.

    Les coordonnées des explications sont (colonne, ligne), à partir du coin supérieur gauche. En mode « Sans hasard », chaque grille est vérifiée par le solveur : elle se termine sans jamais deviner.
