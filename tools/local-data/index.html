Mes données locales

Sauvegardez vos préférences, scores et progressions sur cet appareil. Aucun fichier n'est envoyé sur un serveur.

Neural Style, Relativity et les autres données du site sont exclus. Une sauvegarde ne fonctionne que pour les données de la même origine (protocole, domaine et port) ; un fichier exporté peut être restauré sur une autre origine.

Exporter

Le fichier contient notamment votre pseudo et vos résultats. Conservez-le dans un endroit privé.

Restaurer

Fermez les autres onglets et jeux avant la restauration. Les clés présentes dans le fichier remplacent les valeurs actuelles ; les clés absentes sont conservées. Exportez d'abord vos données.

Aucune opération effectuée.

Après restauration, rechargez le portail et les jeux déjà ouverts pour afficher leurs données actualisées.
